# 1. RAG pipeline*

    1.1. From project directory enter SE_14_RAG_pipeline directory
    1.2. Follow the RAG_pipeline README instructions and setup the RAG_pipeline flask application

# 2. Backend

    1.1. From project directory enter SE_14/backend directory
    1.2. Follow the backend README instructions and setup the student portal flask application

# 3. Frontend

    1.1. From project directory enter SE_14/frontend directory
    1.2. Follow the frontend README instructions and setup the frontend vue application

*: In case of running the project on a system with <12GB VRAM to setup the local LLM model, only follow steps 2 and 3, This will allow you to run the student portal application without the RAG functionality.
